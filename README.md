# Lobstermania 3: Home Remake

A just-for-fun remake of **Lucky Larry's Lobstermania 3** that runs in a web browser.

> ## ⚠️ Disclaimer
>
> - **For educational purposes only.** This project was made to learn how a slot machine game is built: reel maths, animation, sound and game flow.
> - **It's all for fun.** There is no real money anywhere in this game. The credits are play money: they can't be bought, won or cashed out, and you can refill them any time for free.
> - **The artwork belongs to IGT.** *Lucky Larry's Lobstermania*, its characters, artwork, names and logos are the property of IGT (International Game Technology). This project has no connection to IGT and isn't endorsed by them. The images were cut from public promo and gameplay videos for personal, non-commercial use only. Please don't publish or redistribute them.

## Playing

Open `index.html` in Chrome or Edge, or make the single-file version with:

```
python tools/build_single.py
```

That writes `dist/lobstermania.html`, which works on its own on any device.

**Controls:** space = spin / stop · arrow keys = change bet · A = autoplay · F = full screen · M = sound on/off · MENU = settings.

## What's in it

- 5 reels with 720 ways to win, wilds and King Stacks
- **Buoy Bonus**: Classic or Free Games
- **Big Wheel Bonus** with the Mother Lode and Full Trap progressives
- Bonus teases, synthesized sound and music, big-win coin showers, autoplay
- Five generosity levels in Settings

`PLAN.md` has the full background, the rules found online and the build notes.
